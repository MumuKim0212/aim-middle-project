# 고객 제출 서류 샘플 (테스트용 가상 데이터)

대출·대환 심사 로직을 시험하기 위한 **가상 고객 4명**의 제출 서류입니다. 모든 인물, 회사, 금융사, 번호는 가상이며, 모든 쪽에 "SAMPLE · 가상 데이터" 워터마크가 있습니다. 실제 발급 문서가 아닙니다.

- 고객마다 `Suitable_Document`(적합)와 `Disqualified_article`(부적합) 폴더가 있습니다.
- 각 폴더에는 **대출 신청 서류와 대환 신청 서류**가 함께 들어 있습니다. 대출과 대환은 **서로 독립된 시나리오**로 봅니다.
- 파일명 앞부분: `공통_`(대출·대환 모두 사용), `대출_`(신규 대출), `대환_`(대환대출)
- `공통_신용평가_신용정보 조회 결과(은행 조회).pdf`는 고객이 내는 서류가 아닙니다. 은행이 조회하는 **심사 데이터 샘플**입니다.
- 이 문서는 **정답표**입니다. 시스템이나 LLM을 평가할 때 입력 데이터로 넣지 마세요.

관련 기획서: [Loan_Service_main.md](../Loan_Service_main.md), [일반대출_기획서.md](../Loan_Service/일반대출_기획서.md), [정부대출_기획서.md](../Loan_Service/정부대출_기획서.md), [기관대출_기획서.md](../Loan_Service/기관대출_기획서.md), [대환대출_기획서.md](../Refinancing_Service/대환대출_기획서.md)

> 판정에 쓴 기준값(DSR 40%, LTV 70%, 대환 경과 기간 6개월, 서류 발급 1개월 이내 등)은 **테스트용 예시값**입니다. 실제 값은 기획서의 `reg_param`, `REFI-ELIG` 설정에서 정합니다. 월 상환액은 연 4~5.5% 원리금균등을 가정한 근사치입니다.
