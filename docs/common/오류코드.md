## 1. 규칙

- 오류 응답 형식은 `{ code, message, details? }`다 ([공통 5장](공통.md#5-오류-응답-형식)). 프론트는 `code`로 분기하고 `message`는 보조 문구다.
- 모든 `code`는 대문자 SNAKE_CASE다. 필드의 값(enum)은 소문자 snake_case다.
- 파트 문서는 코드 이름만 쓰고 표를 다시 만들지 않는다. 새 코드는 **이 문서에 먼저 추가**하고 파트 문서에서 인용한다.
- 코드 하나는 의미 하나다. 같은 상황이면 파트가 달라도 같은 코드를 쓴다 (예: `ACCOUNT_NOT_FOUND`).
- 타인의 리소스는 없는 것과 똑같이 404다. 코드도 같다.
- 여러 검사에 동시에 걸리면 처음 실패한 단계의 오류만 돌려준다 (처리 순서는 card/00 1.5절 방식을 따른다: 인증 → 입력 검증 → 존재·소유권 → 상태·업무 조건 → 본인 재확인 → 실행).

**HTTP 상태 사용 기준**

| 상태 | 쓰는 경우 |
|:---:|---|
| 400 | 요청 형식·입력값이 틀림 (`VALIDATION_FAILED`) |
| 401 | 로그인하지 않았거나 인증 정보가 틀림 |
| 403 | 로그인은 됐지만 지금은 할 수 없음 (간편비밀번호 설정·재확인 필요, 현재 비밀번호 불일치, 출처 불일치) |
| 404 | 없는 리소스, 타인의 리소스 |
| 405 | 허용하지 않는 메서드 (예: GET으로 로그아웃) |
| 409 | 현재 상태와 충돌 (이미 처리됨, 연결된 항목이 있음, 보유 한도) |
| 422 | 요청 형식은 맞지만 업무 규칙을 어김 (한도 초과, 자격 없음, 잔액 부족) |
| 423 | 잠김 (비밀번호·간편비밀번호 5회 실패) |
| 500 | 서버 오류 |
| 503 | 외부·하위 모듈 호출 실패 |

## 2. 공통 코드

| HTTP | code | 뜻 | details | 비고 |
|:---:|---|---|---|---|
| 400 | `VALIDATION_FAILED` | 입력값 오류 | `fields: [{ field, reason, message? }]` | `message`는 서버가 화면에 바로 보여줄 문구가 있을 때만 (인증 가입 폼 등). reason은 5절 |
| 401 | `LOGIN_REQUIRED` | 로그인하지 않음 | - | 프론트: `/login?next=<원래 경로>` |
| 401 | `SESSION_EXPIRED` | 세션 만료 (마지막 활동 후 30분) | - | 같은 이동에 만료 안내를 붙인다 |
| 403 | `PIN_SETUP_REQUIRED` | 간편비밀번호를 아직 설정하지 않음 | - | 프론트: S-07로 이동 |
| 403 | `PIN_VERIFICATION_REQUIRED` | 5분 안에 간편비밀번호 확인(S-08)을 하지 않음 | - | 프론트: S-08을 띄우고 통과하면 같은 요청을 다시 보낸다 |
| 403 | `ORIGIN_NOT_ALLOWED` | 쓰기 요청의 `Origin` 헤더가 우리 출처가 아님 | - | CSRF 방어 (공통 3장) |
| 404 | `NOT_FOUND` | 없는 리소스 (타인의 리소스 포함) | - | 파트가 더 구체적인 코드를 정했으면 그것을 쓴다 |
| 405 | `METHOD_NOT_ALLOWED` | 허용하지 않는 메서드 | - | |
| 500 | `INTERNAL_ERROR` | 서버 오류 | - | 응답에 내부 정보를 담지 않는다 |
| 503 | `CHAT_UNAVAILABLE` | 자연어 처리(LLM) 호출 실패 | - | 공통 9.3. 화면은 "지금은 대화를 쓸 수 없어요" 안내 |

## 3. 인증·회원 코드

원본 문서: [회원,인증.md](../auth/회원,인증.md). 엔드포인트는 같은 문서 7.3절이다.

| HTTP | code | 뜻 | details | 쓰이는 곳 |
|:---:|---|---|---|---|
| 401 | `INVALID_CREDENTIALS` | 아이디 또는 비밀번호가 틀림. 아이디 없음과 비밀번호 틀림을 구분하지 않는다 | - | `POST /api/auth/login` |
| 401 | `DEVICE_INVALID` | 등록된 기기가 아니거나 기기 쿠키가 위조·만료·해제됨. 서버가 쿠키를 지운다 | - | `POST /api/auth/pin/login` |
| 401 | `PIN_MISMATCH` | 간편비밀번호가 틀림 (로그인 전 인증) | `remainingAttempts` (1~4) | `POST /api/auth/pin/login` |
| 403 | `PIN_MISMATCH` | 간편비밀번호가 틀림 (로그인 후 확인) | `remainingAttempts` (1~4) | `POST /api/auth/pin/verify`, `POST /api/auth/pin/setup` (변경 시 현재 6자리) |
| 403 | `CURRENT_PASSWORD_INVALID` | 현재 비밀번호가 틀림. 로그인 실패와 같은 카운터에 센다 | - | `POST /api/auth/password/change`, `POST /api/auth/pin/setup` (재설정) |
| 423 | `LOGIN_LOCKED` | 비밀번호 5회 실패로 10분 잠김. 시간이 지나면 풀린다 | `until` (ISO 8601) | `POST /api/auth/login`, `POST /api/auth/password/change` |
| 423 | `PIN_LOCKED` | 간편비밀번호 5회 실패로 잠김. 시간이 지나도 풀리지 않고 아이디·비밀번호로 로그인해 재설정해야 한다 | - | `POST /api/auth/pin/login`, `/pin/verify`, `/pin/setup` (변경) |

- 틀린 횟수는 5번째 요청의 응답부터 잠금 코드다 (`remainingAttempts: 0`인 응답은 없다).
- `PIN_MISMATCH`의 HTTP 상태는 로그인 전 인증(`/pin/login`)이 401, 로그인 후 확인(`/pin/verify`, `/pin/setup`)이 403이다. 프론트는 상태가 아니라 `code`로 분기한다.

## 4. 계좌 코드 (초안)

원본 문서: [계좌.md](../account/계좌.md). 아직 구현 전이라 계좌 파트가 구현하면서 조정할 수 있고, 조정하면 이 표를 먼저 고친다.

| HTTP | code | 뜻 | details | 쓰이는 곳 |
|:---:|---|---|---|---|
| 404 | `ACCOUNT_NOT_FOUND` | 계좌 없음 (타인의 계좌, 카드 결제 계좌로 쓸 수 없는 계좌 포함) | - | 전체, 카드 신청 |
| 404 | `PRODUCT_NOT_FOUND` | 상품 없음 | - | 상품 안내, 개설 |
| 409 | `ACCOUNT_STATE_INVALID` | 현재 계좌 상태에서는 할 수 없음 (해지·만기해지된 계좌, 저축예금이 아닌 계좌에 입금 등) | `currentStatus`, `allowedStatuses` | 입금, 이체, 납입, 해지 |
| 409 | `ACCOUNT_COUNT_LIMIT_EXCEEDED` | 상품별 보유 한도 초과 (저축예금 5개, 정기적금 1개) | `productType`, `current`, `max` | 개설 (AF-08) |
| 409 | `SAVINGS_ALREADY_PAID` | 이번 달 납입이 이미 끝남 | - | 적금 납입 (AF-11) |
| 409 | `SAVINGS_COMPLETED` | 12회차를 모두 납입함 | - | 적금 납입 |
| 409 | `ACCOUNT_LINKED_SAVINGS` | 활성 예적금의 지정 저축예금이라 해지할 수 없음 | - | 저축예금 해지 (AF-12) |
| 409 | `ACCOUNT_LINKED_CARD` | 해지 안 된 카드의 결제 계좌라 해지할 수 없음 | - | 저축예금 해지 (AF-20) |
| 422 | `INSUFFICIENT_BALANCE` | 잔액 부족 | `balance`, `required` | 이체, 납입, 예적금 개설 (AF-01, AF-10) |
| 422 | `TRANSFER_TARGET_INVALID` | 이체할 수 없는 계좌 (없는 계좌, 해지 계좌, 예적금 계좌) | - | 이체 (AF-02, AF-06) |
| 422 | `SAME_ACCOUNT` | 출금 계좌와 입금 계좌가 같음 | - | 이체 (AF-03) |
| 422 | `TRANSFER_LIMIT_PER_TX` | 1회 이체 한도(5,000,000원) 초과 | `max` | 이체 (AF-05) |
| 422 | `TRANSFER_LIMIT_PER_DAY` | 1일 이체 한도(10,000,000원) 초과 | `max`, `used` | 이체 (AF-23) |
| 422 | `DEPOSIT_LIMIT_EXCEEDED` | 1회 입금 한도(10,000,000원) 초과 | `max` | 입금 |
| 422 | `CHECKING_REQUIRED` | 저축예금을 먼저 개설해야 함 | - | 예적금 개설 (AF-07) |
| 422 | `CLOSE_TARGET_REQUIRED` | 잔액이 있는데 받을 저축예금이 없음 | - | 저축예금 해지 |

- 금액·기간의 범위 오류(AF-09)와 0원·음수·문자 금액(AF-04)은 `VALIDATION_FAILED`의 reason `OUT_OF_RANGE`, `INVALID_FORMAT`이다.
- 자동이체 실패(잔액 부족)는 사용자 요청이 아니라 배치 결과라 API 오류가 아니다. 거래 내역과 적금 상세에 미납으로 표시한다 (계좌.md 5.3).

## 5.1 대출 코드

원본 문서: [loan/대출서비스_종합정리.md](../loan/대출서비스_종합정리.md). 대출 예외(`backend/app/loan/errors.py`)가 이 코드로 응답한다. 입력 오류는 공통 `VALIDATION_FAILED`를 쓴다.

| HTTP | code | 뜻 | 쓰이는 곳 |
|:---:|---|---|---|
| 403 | `LOAN_CONSENT_REQUIRED` | 필요한 동의가 없어 조회·진행할 수 없음 | 동의, 심사, 외부 조회 |
| 404 | `LOAN_NOT_FOUND` | 상품·신청·대출 없음. 타인의 신청·대출, 만료된 신청 포함 | 전체 |
| 409 | `LOAN_STATE_INVALID` | 지금 단계에서는 할 수 없음(앞 단계를 건너뜀 포함) | 신청 단계 전체, 대출관리 |
| 409 | `LOAN_DUPLICATE_REQUEST` | 같은 `Idempotency-Key`로 이미 처리됨 | 실행, 중도상환 |
| 422 | `LOAN_LIMIT_EXCEEDED` | 승인 한도·상품 한도 초과 | 조건 확정 |
| 422 | `LOAN_GUARDRAIL_VIOLATION` | 안전 검증을 통과하지 못함 | 추천 문구 |
| 429 | `RATE_LIMITED` | 요청이 너무 잦음 | 기존 대출 조회, 심사 |
| 500 | `LOAN_EXECUTION_FAILED` | 대환 실행 중 문제가 생겨 거래를 되돌림 | 대출 실행 |

대출 실행·중도상환·청약철회는 계좌를 움직이므로 계좌 코드 `INSUFFICIENT_BALANCE`(422), `ACCOUNT_NOT_FOUND`(404), `ACCOUNT_STATE_INVALID`(409)와 공통 `PIN_VERIFICATION_REQUIRED`(403)도 그대로 쓴다.

## 6. 필드 오류 사유 (`details.fields[].reason`)

| reason | 뜻 | 주로 쓰는 곳 |
|---|---|---|
| `REQUIRED` | 필수 값이 없음 | 전체 |
| `INVALID_FORMAT` | 형식이 맞지 않음 | 전체 |
| `INVALID_ENUM` | 허용되지 않은 값 | 전체 |
| `OUT_OF_RANGE` | 숫자 범위를 벗어남 | 전체 (금액, 기간, 결제일) |
| `TOO_LONG` | 길이 초과 | 전체 |
| `NOT_ALLOWED` | 이 요청에서는 보내면 안 되는 필드 | 카드 신청 |
| `MUST_BE_TRUE` | 반드시 `true`여야 하는 값 (약관 동의 등) | 가입, 카드 |
| `MISMATCH` | 확인 입력이 서로 다름 | 비밀번호·간편비밀번호 확인 |
| `ALREADY_TAKEN` | 이미 사용 중인 값 | 아이디 |
| `PASSWORD_RULE` | 비밀번호 규칙 위반 | 가입, 비밀번호 변경 |
| `CONTAINS_LOGIN_ID` | 비밀번호가 아이디를 포함함 | 가입, 비밀번호 변경 |
| `SAME_AS_CURRENT` | 현재 비밀번호와 같음 | 비밀번호 변경 |
| `UNDER_AGE` | 만 14세 미만 | 가입 |
| `PIN_TOO_SIMPLE` | 너무 단순한 비밀번호 (간편비밀번호 6자리, 카드 비밀번호 4자리) | 간편비밀번호 설정, 카드 신청 |
| `PRODUCT_TYPE_MISMATCH` | 상품 종류와 카드 종류가 다름 | 카드 신청 |
| `FROM_AFTER_TO` | 시작일이 종료일보다 늦음 | 카드 이용내역 |
| `TO_IN_FUTURE` | 종료일이 오늘 이후 | 카드 이용내역 |
| `PERIOD_TOO_LONG` | 조회 기간이 12개월 초과 | 카드 이용내역 |
