## 1. 전체 방향

- **밝고 부드러운 느낌**으로 통일합니다. 어두운 바탕, 검정 굵은 선, 금색 같은 강한 대비는 쓰지 않습니다.
- 모든 화면이 같은 틀을 씁니다: **흰 카드 + 옅은 그림자 + 파스텔 그라데이션 배너 + 둥근 입체(3D) 그림**.
- 업무(일반·정부·기관·대환·대출관리)마다 **강조색 하나만** 다르게 줍니다. 탭 밑줄, 선택된 필터 칩, 배너 "최대" 배지, 금액 숫자, 카드 태그·아이콘이 그 색을 따릅니다.
- 화면 구성(상단바 → 탭 → 배너 → 필터 칩 → 상품 카드)은 기존 프로토타입과 같습니다. 색과 그림만 바뀝니다.

## 2. 업무별 시안

### 2.1 일반대출 — A 소프트 3D 블루
- **느낌**: 은행 앱다운 신뢰감. 지금 프로토타입의 파란 톤을 그대로 살려서 바꿀 부분이 가장 적습니다.
- **배너**: 흰색에서 연한 하늘색으로 넘어가는 바탕. 금액은 기존 파랑→보라→분홍 그라데이션(`#3b82f6 → #a78bfa → #e879f9`). "최대" 배지는 남색 `#1f5fbf`.
- **그림**: 살짝 기울어진 파란 3D 계산기(화면은 흰색, 버튼 하나는 분홍), 오른쪽 아래 금색 원화(₩) 동전, 주변에 작은 보라·하늘색 점.
- **상품 카드**: 태그 `#f1f5fb` 바탕 + `#3b5b8a` 글자, 금액 파랑, 아이콘 상자 연한 파랑.
- **어울리는 상품**: 직장인 신용대출, 오토론, 예금담보대출 등 일반대출 전체.

### 2.2 정부대출 — B 파스텔 플랫 일러스트
- **느낌**: 따뜻하고 친근함. 전세·내 집 마련처럼 생활과 맞닿은 정책자금에 어울립니다.
- **배너**: 살구색 단색 `#ffe7d6`. 제목 글자 진한 갈색 `#3d2b1f`, 금액 주황 `#e3622f`, "최대" 배지 주황 `#ff8a5b`.
- **그림**: 평면(플랫) 장면 그림 — 주황 지붕의 흰 집, 갈색 문, 하늘색 창문, 굴뚝, 초록 나무, 노란 해, 작은 새.
- **상품 카드**: 테두리 `#f3e3d6`, 태그 연두 `#e9f6ef` + `#2f7a52` 글자, 금액 주황, 아이콘 상자 연한 살구.
- **필터 칩**: 선택된 칩은 진한 갈색 `#3d2b1f`으로 채움.
- **어울리는 상품**: 정책 전세자금(버팀목형), 정책 주택구입자금(디딤돌형).

### 2.3 기관대출 — C′ 라벤더 소프트 (교체됨)
- **바꾼 이유**: 1차 시안 C(어두운 남색 + 금색 선)는 무겁고 어두워서, 밝고 부드러운 느낌으로 다시 그렸습니다.
- **느낌**: "소속 기관과 보증기관이 받쳐 준다"는 안심감.
- **배너**: 흰색 → 연보라 → 연하늘 그라데이션. 제목 `#2b2550`, 금액 `#7c6cf0 → #5aa9f5` 그라데이션, "최대" 배지 `#8b7cf6`.
- **그림**: 보라 3D 회사 건물(흰 창문), 살짝 기울어진 흰 사원증(분홍 얼굴 동그라미), 체크 표시가 있는 하늘색 방패(보증).
- **상품 카드**: 협약(신용) 상품은 연보라 태그·아이콘(사원증 모양), 보증(전월세) 상품은 연하늘 태그·아이콘(방패 모양)으로 구분.
- **어울리는 상품**: 협약기관 임직원 신용대출, 보증부 전세대출(HUG·HF·SGI).

### 2.4 대환 — D′ 민트 & 피치 (교체됨)
- **바꾼 이유**: 1차 시안 D(흰 바탕 + 검정 굵은 선 + 막대그래프)는 딱딱해서, 부드러운 그림으로 다시 그렸습니다.
- **느낌**: "지금 대출을 더 싼 대출로 바꾼다"는 가벼운 이득.
- **배너**: 흰색 → 연민트 → 연살구 그라데이션. 제목 `#173b30`, 금액 `#1fb985 → #4fb3f0` 그라데이션, "최대" 배지 `#2cc28f`.
- **그림**: 왼쪽 살구색 동전(기존 대출)과 오른쪽 민트 동전(새 대출)이 위아래 둥근 화살표로 자리를 바꾸는 모양.
- **금리 말풍선**: 배너 오른쪽 위 흰 알약에 "~~12.9%~~ → 4.5%"처럼 기존 금리(주황, 가운데 줄) → 새 금리(민트). 시안 값은 예시입니다.
- **상품 카드**: 민트 태그·금액·아이콘. 신용대출 갈아타기 카드에는 살구색 알약 "월 이자 약 8만원 ↓ (예시)"를 붙여 절약 효과를 보여 줌 (1,240만원을 연 12.9% → 4.5%로 바꿨을 때의 예시 계산).
- **필터 칩**: 전체 / 신용 / 주택담보 / 전월세.

### 2.5 대출관리 — M 스카이 대시보드 (새로 만듦)
- **느낌**: 내 대출을 표가 아니라 숫자와 색으로 한눈에 읽는 화면.
- **요약 카드(맨 위)**: 흰색 → 연하늘 → 연분홍 그라데이션. "내 대출 총 잔액 · N건", 큰 금액(28px), 그 아래 작은 흰 상자 두 개 — **다음 납입일(D-n, 파랑)**, **이번 달 납입 합계**. 오른쪽 위에 3D 달력 + 금색 체크 동전 그림.
- **대출 카드**: 상품명 + 상태 배지(정상 = 연두, 청약철회 가능 기간 = 살구 "철회 가능 D-n") → 계약 번호 · 업무 · 실행일(경과 개월) → 잔액(24px)과 오른쪽에 처음 대출금 → **상환 진행 막대**(하늘색 그라데이션, "상환 29%" / "만기 날짜") → 금리·월 납입·상환 방법을 회색 작은 상자 3칸으로.
- **기능 버튼 6개**: 글자 버튼 대신 색깔 있는 둥근 아이콘 버튼 + 아래 두 줄 글자.

| 기능 | 아이콘 | 색 |
|---|---|---|
| 상환 스케줄 | 달력 | 하늘 `#3b9cf2` / `#e8f3ff` |
| 중도상환 | 위쪽 화살표 원 | 민트 `#22b281` / `#e5f7ef` |
| 금리인하요구 | 퍼센트 | 라벤더 `#8b7cf6` / `#f1eeff` |
| 청약철회 | 되돌리기 화살표 | 살구 `#e0772e` / `#fff2e6` |
| 기간연장 | 시계 | 청록 `#2aa3c4` / `#e7f6fb` |
| 증명서 발급 | 문서 | 분홍 `#d9558f` / `#fdeff6` |

- 대환으로 실행된 대출 카드는 진행 막대를 민트색으로 그려 일반 대출과 구분합니다.

## 4. 프로토타입에 적용하는 방법

| 프로토타입 부분 | 적용 내용 |
|---|---|
| 탭 (대출 / 대환 / 대출관리) | 탭마다 강조색: 대출 = 파랑, 대환 = 민트, 대출관리 = 하늘 |
| 대출 탭 배너 3장 | 직장인 신용대출 = A 계산기(파랑), 정책 전세자금 = B 집(살구), 협약기관 신용대출 = C′ 건물(라벤더) |
| 대환 탭 배너 2장 | 둘 다 D′ 민트·살구 배너. 신용 갈아타기 = 동전 교환 그림 + 말풍선 "고금리 → 연 4.5%~", 주담대 갈아타기 = 집 그림 + 말풍선 "연 3.8%~" (상품 최저 금리. 고객마다 다른 기존 금리는 배너에 넣지 않음) |
| 대환 상품 카드 | 신용대출 갈아타기 카드에만 "월 이자 약 8만원 ↓ (예시)" 알약 표시 |
| 대출 탭 필터 칩 | 고른 업무의 색으로 채움 (전체·일반 = 파랑, 정부 = 살구/갈색, 기관 = 라벤더) |
| 상품 카드 | 줄로 나뉜 목록 → 둥근 흰 카드. 태그·금액·버튼 색은 상품의 업무 색 |
| 대출관리 탭 | 요약 카드 + 대출별 카드(진행 막대, 정보 3칸, 아이콘 버튼 6개) |
| 신청 단계 화면(오른쪽 칸) | 이번 범위 밖. 기존 파란 디자인 유지 |
