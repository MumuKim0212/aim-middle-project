## 1. 화면 구조와 레이아웃

### 1.1 전체 배치
두 칸(왼쪽 `#app` = 메인, 오른쪽 `#side` = 상세·신청)을 만들어 두고, **보기 방식**에 따라 보여 주는 칸을 정합니다 (main 3.6).

| 보기 방식 | 조건 | 배치 |
|---|---|---|
| **한 화면 전환 (모바일 보기, 기본)** | body에 `single` 클래스. 폭 900px 미만이면 항상 이 방식 | 한 칸만 표시(폭 최대 440px, 가운데, 페이지 전체 스크롤). 메인이면 왼쪽 칸만, 상세·신청이면 오른쪽 칸만 보임 (body의 `open` 클래스 = 메인이 아님) |
| 분할 보기 | body에 `single` 없음, 폭 900px 이상 | **좌우 2칸**. 왼쪽 칸(폭 440px) = 메인, 오른쪽 칸(폭 440px) = 상세·신청. 가운데 정렬, 간격 20px, 각 칸 높이 100vh에서 따로 스크롤 |

- **보기 전환 버튼**: 폭 900px 이상에서만 화면 오른쪽 위(위 12px, 오른쪽 16px, 고정)에 둥근 상자로 「📱 모바일 보기」「🖥 분할 보기」 두 버튼. 고른 버튼은 파란 바탕 흰 글자. 누르면 `setView`로 body 클래스를 바꾸고 맨 위로 스크롤.
- **기억**: 고른 방식을 브라우저 저장소(`localStorage` 키 `loanProtoView`, 값 `single`/`split`)에 저장하고, 처음 열 때 읽어 적용. 저장소를 쓸 수 없으면 기본값 `single`.
- **메인으로 돌아올 때**(집 아이콘·뒤로·「처음으로」·「내 대출 관리로」): 한 화면 전환에서는 맨 위로 스크롤.
- 보기 방식을 바꿔도 신청 상태(`S`)는 그대로입니다.

- (분할 보기) 상품을 눌러도 **왼쪽 메인은 다시 그리지 않습니다**(배너 위치·스크롤 유지). 왼쪽은 탭·필터·대출 목록 내용이 바뀔 때만 다시 그립니다.
- (분할 보기) 오른쪽 칸에 아무것도 열리지 않았을 때는 안내를 보여 줍니다: 계산기 그림 + "상품을 선택해 주세요" + "왼쪽 목록이나 배너에서 상품을 누르면 이쪽에 상세 화면과 신청 단계가 열립니다."
- 선택한 상품 카드는 왼쪽 목록에서 연한 파란 배경 + 왼쪽 4px 파란 줄로 표시합니다.
- 오른쪽 칸에서 **같은 단계 안의 입력**(체크·선택)으로 다시 그릴 때는 슬라이드 애니메이션을 하지 않고 스크롤 위치를 유지합니다. 단계가 바뀔 때만 맨 위로 이동하며 슬라이드 인 합니다.

## 2. 메인 화면

### 2.1 구성 (위에서 아래)
1. 상단바: 집 아이콘 · **"대출 서비스"** · 메뉴
2. 탭: **대출 / 대환 / 대출관리** (선택 탭 파란 글자 + 아래 3px 파란 줄, 줄이 늘어나는 애니메이션). 다른 탭은 없음
3. 대출·대환 탭: 배너(자동 넘김) → (대출 탭만) 필터 칩 **전체 / 일반대출 / 정부대출 / 기관대출** → 상품 카드 목록 → 하단 안내 "이 화면은 기획서 로직을 체험하기 위한 가상 프로토타입입니다. 상품명·금리·한도·기준값은 모두 예시이며 실제 금융상품이 아닙니다."
4. 대출관리 탭: 대출 카드 목록 (11장)

### 2.2 배너 (자동 넘김 3.8초, 전환 0.6초)
| 탭 | 문구 (2줄) | 연결 상품 | 큰 숫자 | 그림 |
|---|---|---|---|---|
| 대출 | 직장인 전용 / 비대면 신용대출 | g1 | 1억원 | 계산기 |
| 대출 | 무주택 세대주 / 정책 전세자금 | p2 | 1억2천만원 | 집 |
| 대출 | 협약기관 임직원 / 우대금리 신용대출 | i2 | 1억5천만원 | 카드 |
| 대환 | 고금리 대출 / 이자 줄이는 갈아타기 | r1 | 1억원 | 계산기 |
| 대환 | 주담대 금리 비교하고 / 한 번에 갈아타기 | r2 | 10억원 | 집 |

- 배너 구성: 큰 문구(28px, 얇은 글꼴) → 상품명 + " ›" (아래 밑줄) → "최대" 배지(남색) → 그라데이션 큰 숫자(46px) → 오른쪽 그림(위아래로 떠다니는 애니메이션 3.2초) → "바로 신청하기 ›"
- 아래 점(dot): 현재 점은 가로로 길어진 파란 막대. 점을 누르면 해당 배너로 이동
- **배너를 누르면 해당 상품의 상세 화면**이 열림

### 2.3 상품 카드
| 줄 | 내용 |
|---|---|
| 1 | 설명 한 줄(회색 15px) |
| 2 | 상품명(굵게 21px) |
| 3 | "최대" + **금액(파랑 21px)** + 세로선 + "기간 최소 ~ 최대" (12의 배수면 "년", 아니면 "개월", 허용 기간이 하나면 그 값만. 예: 기간 1년 ~ 5년 / 기간 2년) |
| 4 | 파란 테두리 버튼 「대출신청」(대환은 「갈아타기 신청」) |
| 오른쪽 위 | 회색 태그 "업무명 · 담보 종류" + 오른쪽 화살표(›) |

- **카드를 누르든 카드의 신청 버튼을 누르든 모두 상품 상세 화면**이 열립니다. 상세 화면의 신청 버튼을 눌러야 신청 단계가 시작됩니다.
- 카드는 차례로 아래에서 올라오며 나타남(0.45초, 카드마다 0.06초 지연)

### 2.4 금액 표시 규칙 (`kwon`)
- 먼저 원 단위로 반올림합니다.
- 1만원 미만: 원 단위 콤마 → 예: 5,000원
- 1만원 이상: 억 = 1억으로 나눈 몫, 만 = (1억으로 나눈 나머지 ÷ 1만)을 **반올림**한 값. "N억" + (만이 0이 아니면 " M,MMM만") + "원" → 예: 2억 2,200만원, 1억원, 3,000만원 (만원 미만 끝자리는 반올림되어 표시에서 사라짐)
- 원 단위 그대로 보여 줄 곳(월 상환액, 이자, 스케줄 등)은 `won` = 원 단위 반올림 + 콤마 + "원"
- 날짜는 YYYY.MM.DD, 스케줄 표의 납입일은 YY.MM.DD
- 음수는 "-" 붙임

### 4.3 단계별 화면과 동작

#### precheck (정부 G01)
- 안내: "조회 동의 전이라 입력값으로만 간단히 확인합니다. 실제 자격은 행정정보로 확정합니다(G04)."
- 입력: 무주택(예/아니오), 혼인(미혼/기혼), (기혼이면 "부부합산") 연 소득(만원), 세대 순자산(만원)
- 판정 (예시 기준): 소득 기준 = 주택담보 7,000만 / 전세 5,000만, **기혼이면 ×1.2** / 순자산 기준 4.5억 / 무주택이어야 함 → 항목별 충족·미충족 배지
- 모두 충족: 초록 상자 "사전 확인 충족 — 참고 결과이며, 서류·행정정보 확인 후 확정됩니다." 버튼 「자격 충족 · 다음」
- 하나라도 미충족: 빨간 상자 "정책 자격 미충족" + 사유(POL-HOME-OWNED / POL-INCOME-OVER / POL-ASSET-OVER 문구) + 버튼 「같은 목적의 일반대출로 전환」, 하단 버튼 「처음으로」
- 일반대출 전환: 같은 담보 종류의 일반 상품으로 바꾸고 동의·고객정보를 유지한 채 새 흐름 1단계부터 시작, 알림 "일반대출(상품명)로 전환합니다. 받은 동의·정보는 재사용합니다."

- 「다음」 활성화 조건: 필수 전부 체크 (+ 정부·기혼이면 배우자 동의 완료)

#### fetch (대환 R03)
- 진행 애니메이션 4줄: 동의 게이트 통과 / 마이데이터 전송 요구 / CB 대출 현황 교차 확인 / 대출 정보 정규화(RLLM-2)
- 끝나면 "조회된 대출 N건" 목록(금융사, 종류·금리·남은 개월, 잔액). 버튼 「조회 결과 확인」 (애니메이션 끝나야 활성화)

#### targets (대환 R04)
- 대출별 카드: 체크박스, 금융사·종류, 배지(대환 가능/불가), 잔액·금리·실행 후 개월·남은 개월, 불가 사유 코드
- 불가 규칙 (예시): 연체 → `REFI-DELINQ` / 실행 후 < 6개월 → `REFI-TOO-RECENT` / 가압류 → `REFI-LEGAL-HOLD` / 남은 기간 < 6개월 → `REFI-SHORT-REMAIN` / 담보 차량번호 불일치 → `ASSET-MISMATCH`. 불가 대출은 체크 불가
- 가능한 대출을 고르면 "대환 신청 금액 (잔액 + 예상 중도상환수수료)" 표시
- **모두 불가**: 빨간 상자 "대환 불가 — 대환 가능한 대출이 없습니다. 기존 금융사에 금리인하요구권을 쓰는 방법을 안내합니다." + 하단 「처음으로」
- 일부 가능하지만 아무것도 안 골랐으면 「다음」 비활성화

#### profile (C03)
- 안내: "**금소법 적합성 원칙**(밑줄 링크)에 따른 고객정보확인서입니다. 양식 보기"
- 입력: 성명, 직업(급여소득자/개인사업자/프리랜서/연금소득자), 재직(사업) 기간(개월), 연 소득(만원), 기존 대출 월 상환액(만원), 보유 자산(만원), 최근 1년 연체 이력(없음/있음)
- 대출: 희망 금액(만원, 라벨에 "(최대 N원)") + 희망 기간(선택) / 대환: 자동 금액 상자 + **희망 대환 기간 선택**(기본값 = 기존 남은 기간과 가장 가까운 허용 기간, 그 옵션에 "(기존 남은 기간과 가장 가까움)") + 실시간 계산 상자(선택 기간, 기존 남은 기간, 예상 월 상환액, 기존 대상 월 상환액, 예상 총 이자, 월 부담 변화 ±, 기간이 남은 기간보다 길면 기간 함정 경고)
- 상환 방법, 금리 선호(고정/변동/혼합형/상관없음)
- 담보 정보: 전월세(임차보증금, 주택 시세, 선순위 채권) / 주택담보(주택 시세, 매매가) / 자동차(차량 가격) / 예금담보(담보 예금 잔액)
- **적합성 판정 상자** (값을 바꿀 때마다 즉시 갱신)
  - 상환 부담률 = (유지되는 기존 월 상환 + 신규 예상 월 상환) ÷ (연 소득÷12). 신규 월 상환은 **상품 최고 금리**, 희망 금액(대환은 자동 금액), 기간, 상환 방법으로 계산. 대환은 대상 대출 월 상환을 기존에서 뺌
  - 판정: 소득 0 이하(예금담보 제외) 또는 부담률 > 70% → 부적합 / 연체 이력 있음 → 주의 / 그 외 적합
  - 표시: 배지(적합/주의/부적합), 계산식과 % , 막대(기준 70%), 주의면 "최근 1년 연체 이력이 있어 심사에서 불리할 수 있습니다."
  - 부적합이면: "금소법 적합성 원칙(링크)에 따라 현재 조건으로는 상품을 권유할 수 없습니다." + 체크박스 "대출 업무 진행이 불가할 수 있는 점을 인지하고 있으며, 신용 조회 등 관련 심사 절차 진행에 동의합니다."
  - 항상 맨 아래: "※ 본 결과는 입력한 정보에 따른 결과이므로 심사 결과는 달라질 수 있습니다."
- 「금소법 적합성 원칙」 설명 창: 제목, "「금융소비자 보호에 관한 법률」 제17조·제18조 요약 · 정확한 해석은 준법감시 확인 필요", 4개 항목(고객 정보 파악 / 부적합 상품 권유 금지 / 확인과 보관 / 고객이 직접 신청하는 경우 적정성 원칙), "판정 기준(70%)은 예시값", 「확인」
- **조정 안내 창** (부적합 체크박스를 체크하거나, 체크 후 「다음」을 누르면 열림): main 5.2.1 계산식 그대로. 선택지 ①금액 조정 ②기간 조정 ③그대로 진행, 불가 선택지는 사유와 함께 흐리게. 기본 선택은 가능한 첫 조정안(없으면 ③). 「이전」 = 창 닫기, 「다음」 = ①·② 값 적용 또는 ③ `suitOverride` 기록 후 다음 단계로, 알림 "금액을 N원으로 조정했습니다" / "기간을 N개월로 조정했습니다" / "현재 조건으로 심사를 진행합니다 (고지 확인 기록)"
- **한도 초과**: 희망 금액 > 상품 최대면 알림 "한도금액을 초과하였습니다."(초과 상태로 바뀔 때 한 번), 입력란 아래 빨간 글씨 "한도금액을 초과하였습니다. 이 상품의 최대 한도는 N원입니다.", 입력란 빨간 테두리
- 「다음」 활성화: (적합/주의 또는 부적합+체크) 그리고 한도 초과 아님

#### policycheck (정부 G04)
- 진행 애니메이션 5줄: 세대 구성 확인 / 무주택 확인(세대원 전원) / 소득 기준(부부합산) / 자산 기준 / 중복 이용 확인. 값은 precheck 입력값과 같은 기준
- 끝나면 충족: "정책 자격 충족" / 미충족: "정책 자격 미충족" + 「일반대출로 전환」, 하단 「처음으로」

#### guarantee (기관 A I04-A·I07)
- 상자: (선순위 + 보증금) ÷ 시세 = N% 막대, "기준 90% 이하 (예시)"
- 보증기관 3곳 카드를 **실질 비용 오름차순**으로 정렬, 1위에 "실질 비용 최저" 배지
  - 보증료율(예시): HUG 연 0.13% / HF 연 0.05% / SGI 연 0.18%, 상한: HUG 4억 / HF 2.22억 / SGI 5억
  - 보증 가능 = 비율 ≤ 90% 그리고 보증금 ≤ 상한×1.25
  - 보증 한도 = min(보증금×0.8, 상한), 2년 이자 = 한도×예상 금리×2, 2년 보증료 = 한도×보증료율×2, 실질 비용 = 이자 + 보증료
- 카드를 눌러 선택(불가 카드는 "보증 대상 기준을 충족하지 않습니다" 알림). 기본 선택 = 가능한 첫 카드
- 모두 불가: 빨간 상자 "보증 불가" + `COL-DEPOSIT-OVER-VALUE` 문구, 하단 「처음으로」
- 안내: "여러 보증기관에 동시에 신청하지 않고, 선택한 한 곳에만 신청합니다 (신용조회 기록 최소화)."

#### affiliation (기관 B I04-B)
- 입력: 협약기관 선택((주)가상전자 / 가상공사 / 가상대학교병원), 사번, 고용 형태(정규직/계약직), 버튼 「협약기관 재직 확인」
- 누르면 2줄 애니메이션(협약기관 재직 확인 API / 고용 형태·재직 기간 검증) → 정규직이면 "재직 확인 완료", 계약직이면 "협약 대상 아님" + `ORG-EMP-TYPE` + 「일반 신용대출로 전환」, 하단 「처음으로」
- 기관 미선택 시 알림 "협약기관을 선택하세요"

#### docs (C04 증빙)
- 버튼 「🔗 공공기관 자동 연동 (건강보험·국세청)」: 자동 연동 동의가 없으면 창(설명 + 「동의하고 연동」), 있으면 0.9초 후 자동 연동 가능 서류를 "공공기관 연동 완료 · 서류 제출 생략"으로 표시, 알림 "N건 연동 완료"

#### review (C05 심사)
- 안내: "네 업무가 같은 심사 파이프라인을 씁니다 (main 6.2의 1~7단계, 수기 심사 분기는 생략). 기준값은 예시입니다."
- 단계 애니메이션(0.75초 간격), 각 줄에 결과 아이콘(✓ 초록 / ! 주황 / ✕ 빨강)과 설명. 계산은 6장
- 끝나면 「결과 보기」 활성화

#### result (C06, 대환 제외)
- 거절·보완이면 6.4 판정 화면
- 승인/조건부: 상자 "승인" 또는 "조건부 승인", "승인 한도 N · 예상 금리 연 N%" (+조건부 사유와 "→ 한도 감액")
- "고객님께 권장하는 상품 — 총 이자 기준 · 수익성 미반영": 7장의 세 가지 안, 1위에 "조건에 가장 유리" 배지, 카드 눌러 선택, 검증 칩이 0.12초 간격으로 초록으로 바뀜
- 버튼 「이 상품으로 진행」 → 금액 = min(희망, 승인 한도)

#### compare (대환 R08·R09)
- 거절·보완이면 6.4 판정 화면. 아니면 8장 계산 결과
- 상자: BENEFICIAL "갈아타면 이득" / TRADE_OFF "월 부담만 감소" / NOT_BENEFICIAL "갈아타면 손해" + 순 절감액 + "N개월째부터 이득"
- 비교표 행(항목 / 기존 / 대환 후): 기간(남은 N개월 / M개월 (고객 선택)), 금리(기존은 잔액 가중 평균, 소수 2자리), 월 납입액, 남은 총 이자, "대환 비용 (중도상환수수료·인지세 예시)"(기존 칸 "-"), **순 절감액**(유리 초록·불리 빨강). 월 납입액·총 이자는 대환 후 값이 기존보다 작으면 초록, 크면 빨강. 새 금리는 항상 초록
- 검증 칩 RV1~RV6 (모두 통과 표시)
- 불리면 체크박스 "불리하다는 고지를 확인했으며 그래도 진행합니다 (refi_override 기록)" — 체크 전 하단 「처음으로」, 체크 후 「대환 진행」

#### terms (C07)
- 금액: 대출은 슬라이더(최소 = 상품 최소, 최대 = min(승인 한도, 상품 최대), 100만 단위) + 큰 금액 표시 / 대환은 고정 금액
- 기간 선택, 상환 방법, 매월 납입일(5/10/15/20/25, 기본 25), 자동이체 출금 계좌(기본 "OO은행 1002-***-123456"), 협약(B)은 [선택] 급여공제(LN-23), [필수] 자동이체 출금 동의(체크 고정)
- 실시간 상자: 월 상환액, 총 이자, 적용 금리(예상), 상환 부담률(70% 초과 시 빨강 + "상환 부담이 적합성 기준을 넘습니다. 금액이나 기간을 조정하세요.")

#### pricing (C08)
- 시작 금리 r0 = 고른 추천안 금리(대환은 비교 금리, 없으면 심사 금리)
- 구성 표시: 정부 "정책 금리표", 협약 "협약 금리표", 그 외 "기준금리 3.10% + 가산금리 (r0 − 3.10)%"
- 우대 체크: 급여 이체 −0.2%p(기본 해제) / 자동이체 3건 이상 −0.1%p(기본 체크) / 카드 사용 월 30만원 이상 −0.1%p(기본 해제)
- 최종 금리 = max(상품 최저 − 0.3, r0 − 우대 합계), 소수 둘째 자리
- 표시: 월 상환액, 총 이자, 보증부(A)는 보증료 = 금액 × (guarantee 단계에서 고른 보증기관의 보증료율: HUG 0.13% / HF 0.05% / SGI 0.18%) × 기간/12 와 실질 비용(총 이자 + 보증료)
- 상환 스케줄 앞 12회(회차·원금·이자·납입액·잔액) + 스케줄표 PDF 링크, 안내 "약속형 우대 조건을 지키지 못하면 다음 금리 변경일에 해당 우대가 빠집니다."
- 버튼 「금리 확정」

#### explain (C09)
- 핵심설명서 상자: 대출 금액, 기간, 최종 금리, 월 상환, 연체 이자(최종 금리 + 3), 중도상환수수료 "3년 이내 부과"
- 설명서 스크롤 상자(높이 220px): 상품 개요 / 금리 / 상환과 수수료 / 연체 시 불이익 / (정부) 정책 의무 / (협약) 협약 특약 / (보증) 보증 / 고객의 권리 / "— 끝까지 읽었습니다 —". 끝까지 스크롤해야 배지가 "끝까지 읽음"으로 바뀜
- 이해 확인 O/X:
  1. 변동금리는 시장 금리가 오르면 월 상환액이 늘어날 수 있다. (O)
  2. 계약서류를 받은 날(또는 실행일)부터 14일 안에는 청약철회를 할 수 있다. (O)
  3. (대출) 계약일로부터 3년 안에 중도상환해도 수수료는 전혀 없다. (X) / (대환) 대환 시 기존 대출의 중도상환수수료는 은행이 대신 내 준다. (X)
  4. (정부만) 정책자금 대출 중 추가로 주택을 사면 대출금이 회수될 수 있다. (O)
- 오답이면 알림 "설명서의 해당 부분을 다시 읽어 보세요". 끝까지 읽음 + 전부 정답이면 「설명을 이해했습니다」 활성화

## 6. 계산식과 기준값 (예시)

### 6.1 상환 계산 (월 금리 r = 연 금리 ÷ 1200)
| 상환 방법 | 월 상환액 | 총 이자 |
|---|---|---|
| 원리금균등 | P·r ÷ (1 − (1+r)^−n) | 월 상환액 × n − P |
| 원금균등 | P/n + P·r (첫 달) | P·r·(n+1)/2 |
| 만기일시 | P·r | P·r·n |

### 6.2 심사 (`evaluate`, main 6.2를 단순화)
| 단계 | 규칙 |
|---|---|
| 신용점수 | 3.3 표 |
| 예상 금리 | 정부: 최저 + (소득 > 6천만 0.5 / > 4천만 0.25 / 그 외 0) · 협약(B): 최저 + (점수 < 800이면 0.4) · 그 외: min(최고, max(최저, 최저 + max(0, 920 − 점수)/100 × 0.9)) · 소수 둘째 자리 |
| (적합성 확인) | 조정 안내 창에서 ③을 고른 경우 첫 줄 "적합성 확인"(주의): "적합성 부적합 상태 · 고객이 고지를 확인하고 심사 진행에 동의함 (suitability_override 기록)" |
| 1 결격 | 시나리오 현재 연체 → KO-DELINQ-CURRENT, 폐업 → KO-BIZ-CLOSED |
| 2 소득 | 예금담보 제외, 연 소득 < 2,000만 → INC-BELOW-MIN, 급여소득자 재직 < 12개월 → INC-TENURE-SHORT |
| 3 신용 | 점수 < 600 → CRD-SCORE-LOW, 다중채무 ≥ 5 → CRD-MULTI-DEBT, 조회 ≥ 7 → CRD-INQUIRY-MANY |
| 4 DSR | 스트레스 금리 = 예상 금리 + 1.0. 연간 원리금: 전월세·예금담보 = P × 금리, 만기일시 = P ÷ max(n/12, 1) + P × 금리, 그 외 = 월 상환 × 12. DSR = (유지되는 기존 월 상환 × 12 + 신규 연간) ÷ 연 소득. 대환은 대상 월 상환을 뺌. DSR 여유 한도: 상품 최대 금액에서 DSR ≤ 40%이면 **상품 최대 그대로**, 아니면 0~상품 최대 사이 이분 탐색 40회(중간값이 40% 이하면 아래쪽 끝을 올림)로 찾은 값. 마지막에 100만원 단위 내림 |
| 5 담보 | 주택담보: 한도 = 시세×0.7 − 선순위, 초과 → COL-LTV-OVER(조건) / 전월세: 선순위+보증금 > 시세×0.9 → (선순위>0이면 COL-SENIOR-LIEN) + COL-DEPOSIT-OVER-VALUE(거절), 한도 = 보증금×0.8 / 자동차: 차량가×0.9 / 예금: 예금×0.95 / 신용: 없음 |
| 6 한도 | min(상품 최대, DSR 여유, 담보 한도), 100만 단위 내림 |
| 7 판정 | 결격·소득·신용·담보(거절)·(DSR 여유 < 상품 최소면 DSR-OVER) 중 하나라도 → **거절** / 서류 결함 있음 → **보완** / 한도 < 신청 금액 → **조건부 승인**(DSR > 40%면 DSR-OVER, 담보 조건 코드) / 그 외 **승인** |

### 6.3 적합성·조정 안내·한도 초과
- main 5.2.1과 같음 (기준 70%, 상품 최고 금리 사용, ①·② 계산식, 불가 조건). 100만 단위 내림, 상품 최소 미만이면 ① 불가
- 한도 초과: 희망 금액 > 상품 최대 (대환 제외)

## 7. 추천 (result)
- 금액 = min(희망, 승인 한도), 세 가지 안: 비대면 전용형(심사 금리 − 0.15, 변동) / 변동금리형(심사 금리, 변동) / 고정금리형(심사 금리 + 0.3, 고정)

| 대환 비용 | Σ 중도상환수수료 + (잔액 합계 > 5,000만이면 인지세 고객 부담분 35,000원, 예시) |

| 새 대출 | 금액 = 대환 금액 Σ(잔액 + 중도상환수수료) (**인지세 제외**, 조건·금리·완료 화면과 같은 금액), 기간 = **고객이 고른 기간**, 상환 방법 = 고객 선택, 금리 = 심사 예상 금리 |

| 손익분기 | 월 차이(기존 월 − 새 월)를 누적해 대환 비용 이상이 되는 첫 달 |

### 12.6 그 밖의 동작 규칙
- 체험 고객 시나리오는 고른 상품의 종류와 관계없이 모든 상품에 적용됩니다(예: Kim을 골라 주택담보 상품을 신청해도 Kim 값 사용).
- 대환 대상 선택에서 불가 대출은 체크할 수 없고, 「다음」을 누를 때 불가 대출은 자동으로 선택 해제됩니다.
- 서류 보완(「서류 다시 제출」): 보완 가능 코드만 지우고 첨부를 모두 비운 뒤 증빙 단계로 돌아가 **처음부터 다시 심사**합니다. 체험 고객의 결함 코드는 증빙 검증 때마다 다시 붙으므로, 부적합 고객은 보완해도 같은 결과가 나옵니다(체험 고객은 자동 첨부도 다시 하지 않음).
- 조건 단계에서 금액은 승인 한도를 넘지 않도록 자동으로 줄입니다. 상환 부담률 계산에는 기존 월 상환액 전체를 씁니다(대환 대상 제외 없음).
- 증명서 발급 창의 "완제 확인서"는 완제 상태에서만 활성화되지만, 완제된 대출은 기능 버튼이 숨겨지므로 체험 화면에서는 발급할 수 없습니다(데모 한계).

### 14.3 설명서 본문 (explain 스크롤 상자)
1. **상품 개요** — "{상품명}은(는) {대상}를 대상으로 하는 {담보 종류} 대출입니다."
2. **금리** — 정부: "정책 금리표에 따르며 공고 변경 시 다음 금리 변경일부터 적용될 수 있습니다." / 그 외: "기준금리 + 가산금리 − 우대금리로 정합니다. 변동금리는 기준금리 변동 주기마다 다시 정해집니다."
3. **상환과 수수료** — "중도상환수수료 = 상환 원금 × 수수료율 × 남은 기간 ÷ 대출 기간. 계약일로부터 3년이 지나면 부과하지 않습니다." + (대환) " 기존 대출의 중도상환수수료는 고객이 부담합니다."
4. **연체 시 불이익** — "지연배상금(약정 금리 + 연 3%p)이 붙고, 연체가 이어지면 기한의 이익이 상실될 수 있습니다." + (신용 제외) " 담보물이 법정 절차로 처분될 수 있습니다."
5. (정부) **정책 의무** — "실행 후 정해진 기간 안에 전입·실거주해야 하며, 추가 주택을 취득하면 대출금이 회수될 수 있습니다." / (협약 B) **협약 특약** — "퇴직·휴직·협약 해지 시 일반 금리로 전환되거나 상환 방법을 협의합니다." / (보증 A) **보증** — "보증료가 별도로 들며, 보증 사고 시 보증기관이 고객에게 구상권을 행사할 수 있습니다."

### 14.4 약정 확인 문장
1. 대출 금액·금리·기간·상환 방법을 확인했습니다.
2. 연체 시 지연배상금과 기한의 이익 상실에 대해 들었습니다.
3. 중도상환수수료와 청약철회권에 대해 들었습니다.
4. 약관과 상품설명서를 받았습니다.
5. (대환) 대출금은 기존 대출 상환에만 쓰이며, 상환이 실패하면 대환대출이 취소됩니다.
